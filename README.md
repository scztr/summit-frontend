# Summit — Frontend

Сторінка каталогу гір. Отримує дані з API Summit і показує назву,
висоту, опис та фото гори. Кнопка «Оновити» повторно завантажує дані.

Використано HTML, CSS та JavaScript.

## Як запустити проєкт

Потрібен Python 3.

1. Запустіть бекенд Summit за інструкцією в його репозиторії.
   Адреса бекенду: http://127.0.0.1:8000.

2. У папці фронтенду виконайте:

   ```bash
   python3 -m http.server 3000
   ```

3. Відкрийте http://localhost:3000.

Фронтенд звертається до `http://127.0.0.1:8000/api/v1/mountains`.
На бекенді потрібно дозволити CORS для `http://localhost:3000`.

Якщо гори ще не додані, сторінка покаже повідомлення про порожній каталог.
Якщо API недоступне, з’явиться повідомлення про помилку.
